# BURSEC PROJECT

App web instalable (PWA) para aprender en vez de hacer scroll: ciberseguridad (auditoría web, redes, Active Directory, pentesting, SOC), sistemas ASIX (redes, Linux, Windows Server, Docker, SQL), empresa (cómo funcionan un banco, una fábrica, un almacén...) y carrera profesional.

- **Feed** infinito de preguntas con XP, combos, cofres sorpresa y repetición espaciada.
- **Teoría** desde cero con ejemplos, buscador y exámenes por tema.
- **Retos diarios**, logros, niveles, rachas y escudos de racha.
- Funciona sin conexión. Progreso guardado en el dispositivo; se pasa entre iPhone y Mac con un código desde Perfil.

## Instalar
- **iPhone:** abre la web en Safari → Compartir → «Añadir a pantalla de inicio».
- **Mac:** Safari → Archivo → «Añadir al Dock».

Sin servidores ni coste: alojada gratis en GitHub Pages → https://bursec-official.github.io/bursec-project/
