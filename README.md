# ROOTSTREAK

Aprende ciberseguridad, sistemas y empresa en vez de hacer scroll.

App web instalable (PWA): teoría desde cero con ejemplos, prácticas de preguntas con repetición espaciada, exámenes por tema, XP, niveles, rachas, retos diarios y logros. Funciona sin conexión.

**Temas:** auditoría web (OWASP, XSS, inyección SQL), auditoría de redes, VLAN y Wi-Fi, seguridad de Active Directory, empresa segura, pentesting (camino OSCP), analista SOC, redes, Linux, Windows Server, Docker, SQL, cómo funcionan las empresas (banco, fábrica, almacén…), carrera profesional, C#/.NET y Claude Code.

## Instalar
- **iPhone:** abre la web en Safari → Compartir → «Añadir a pantalla de inicio».
- **Mac:** Safari → Archivo → «Añadir al Dock».

Alojada gratis en GitHub Pages: https://bursec-official.github.io/rootstreak/
